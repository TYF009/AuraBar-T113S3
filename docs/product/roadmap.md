# Roadmap

Priorities describe intended outcomes, not delivery dates or committed commercial support.

## Current foundation

- Music & Focus: native audio service, bounded queue and storage corrections.
- Desktop Link: authenticated companion, actual process state and USB snapshots.
- Coding Companion: Codex JSONL mapping, review cards and responsive tab/scroll behavior.

## Next engineering milestones

1. Complete binary-asset provenance and release prerequisites, then publish clearly scoped application previews.
2. Improve first-use setup with consistent environment checks, configuration and lifecycle commands.
3. Document and prepare an obtainable toolchain/SDK baseline for automated ARM builds.
4. Close notification-recovery, network, long-duration and restart acceptance gaps.
5. Move repeated version definitions toward generated build metadata; profile builds need explicit feature/configuration support.

## Future product integrations

- Test-runner-specific evidence and quieter notification preferences.
- Interactive task control only after an explicit authenticated command/approval design.
- Connected-appliance adapters with real data sources.
- Optional voice and transcription after checking the existing microphone/audio chain.
- Auxiliary vehicle scenes remain exploratory until their actual interface and integration requirements are defined.

[Current capability state](status.md) is the authority for what can be demonstrated today.
